# Сайт-приглашение «Фантастический цирк»

## Где менять текст

Откройте файл `content.js` в простом текстовом редакторе.

- Название сайта — поле `title`.
- Обращение к гостю — `greeting`.
- Два абзаца письма — строки внутри `paragraphs`.
- Дата, время и адрес — `eventDetails`.
- Имена гостей — поля `guest` в списке `tickets` (места уже подготовлены для 14 человек).

Меняйте только текст внутри кавычек. Кавычки и запятые вокруг него оставляйте.

## Как добавить персональные PDF-билеты

1. Положите PDF в папку `assets/tickets`.
2. Назовите файл по номеру, например `ticket-01.pdf` для первого гостя, `ticket-02.pdf` для второго.
3. В `content.js` найдите этого гостя и впишите путь в поле `pdf`, например:

   `pdf: "assets/tickets/ticket-01.pdf"`

4. Сохраните `content.js`. На карточке появится ссылка «Открыть билет PDF».

Сайт статический: добавленные PDF будут доступны по прямым ссылкам всем, у кого есть адрес файла. Если в билетах есть личные данные, учитывайте это при публикации.

## Как показать новые изменения онлайн

После публикации сохраните обновлённые `content.js` и PDF в проекте и отправьте новую версию на хостинг. При подключённой публикации через Vercel обновления можно выкладывать повторно без изменения адреса сайта.

Откройте `index.html` для локального просмотра. Файлы изображений и шрифта находятся в папке `assets`.

Музыка: положите свой файл под именем `assets/music.mp3` (текущий файл — circus.mp3). Он запускается при открытии шкатулки и повторяется по кругу; кнопка вверху включает и выключает звук.
